# c-homework-vs2010

> 把教材照片里的 C 语言练习，做成可以直接提交的作业包。

一个面向 Windows 的 AI 技能（Skill）包：给它教材照片，产出 `.c` 源码 + IDE 代码截图 + 运行结果截图，最后打包成 zip。

---

## 这个是什么

这是给 **Claude Code / DSH** 这类 AI 编程助手用的**技能文件**，不是可执行程序。

把 `SKILL.md` 放进助手的 skills 目录，助手在处理「C 语言教材练习」任务时就会自动加载它，按里面写好的流程干活，而不是每次从零摸索。

---

## 解决什么问题

用 AI 写 C 作业，难点从来不在写代码，而在**把结果截成能交作业的样子**。这个技能把踩过的坑都固化了：

- 中文注释变乱码
- 截图截到桌面而不是控制台
- 只出 `.obj` 不出 `.exe`
- 文件名变成 `缁冧範...png` 这种乱码
- VS2010 启动慢，截到启动画面

## 铁律摘要

完整版见 `SKILL.md`，这里摘出最容易踩的几条：

**1. 先看现状，再动手**
列桌面、读已有的作业文件夹，确认命名风格（`例1.9.c` 用点号？`练习2-7.c` 用横杠？）。照抄现有风格，不自创。

**2. 不动用户的文件夹结构**
需要放新内容时先问：并入原文件夹，还是新建独立的？默认原文件夹保持原样。

**3. 破坏性操作一律走回收站**
并在回复里明说「已移入回收站，可恢复」。恢复要遍历 verbs 按名字匹配，不能用索引。

**4. 每张截图必须当场读一遍**
批量跑完再统一看 = 连废 3~4 轮。

**5. 不要 `Stop-Process conhost`**
会把托管自身会话的控制台一起杀掉，之后所有命令报 `0xE9`。只关自己启动的那个窗口。

**6. 不要删 `.exe`**
清理临时文件时别 `Remove-Item *.exe`，否则后续「不是内部或外部命令」，截出来是空屏。

**7. 能在 IDE 里做就别写命令行胶水**
但编译本身用 `cl` 批量更快——难的是截图，不是编译。

## 环境要求

| 项 | 要求 |
|---|---|
| 系统 | Windows（已在 Windows 11 实测） |
| 编辑器 | Visual Studio 2010 或 VS2022 |
| 编译 | MSVC `cl`（VS2010 默认路径 `D:\Program Files (x86)\Microsoft Visual Studio 10.0\VC\vcvarsall.bat`） |
| Shell | PowerShell 5.1 或 7 |
| 编码 | 源码 UTF-8 with BOM，控制台 GBK（936） |

## 怎么用

### 在 DSH 里

放到 DSH 的 skills 目录即可：

```
%USERPROFILE%\.dsh\skills\c-homework-vs2010\SKILL.md
```

### 在 Claude Code 里

```
%USERPROFILE%\.claude\skills\c-homework-vs2010\SKILL.md
```

### 手动使用

不需要自动加载的话，直接在对话里说「按 SKILL.md 的流程做」并附上文件内容也可以。

---

## 注意事项

- 这个技能**为个人作业场景编写**，路径、命名习惯依赖本机环境。换机器使用前，先按「铁律」第 1 条确认现状。
- `SKILL.md` 里的路径示例（`D:\Program Files (x86)\...`）**不是通用的**，按自己的 VS 安装位置改。
- 截图尺寸等参数按 4K 屏幕调过，换分辨率可能需要调整。
