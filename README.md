# c-homework-vs2010

C 语言教材练习（VS2010/VS2022）技能包，用于把教材照片要求的练习做成可提交的作业包：
`.c` 源码 + IDE 代码截图 +（可选）运行结果截图，最后打包成压缩文件。

## 内容

- `SKILL.md` — 技能主文件，包含何时使用、铁律条款、源码规范、编译验证与截图流程。

## 用途

面向「给出教材照片 → 产出可提交作业包」的场景，覆盖：

- 中文编码（UTF-8 with BOM）
- VS2010 窗口截图（`PrintWindow` 抓整窗）
- 经典控制台抓取
- 回收站恢复（破坏性操作一律走回收站）
- 命名规范与验收自检

## 兼容性

- 设计环境：Windows
- IDE：Visual Studio 2010 / 2022
- 检索方式：`.c` 源码、MSVC 工具链（`cl`）

## 说明

该技能为个人使用场景编写，依赖本机桌面上的作业文件夹结构与命名习惯。
在其他机器上使用前，请先按 `SKILL.md` 中「铁律」第 1 条确认现状。
